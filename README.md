# Jaguar Website

A website that reimagines the official Jaguar website, presenting a refreshed web experience with a focus on showcasing Jaguar models exclusively featured in this project.

Live Demo: [Jaguar Website](https://jaguar-website-nwptd9hj5-kalel1.vercel.app/)

## Overview

This project explores a redesigned Jaguar website, combining a modern visual approach with an organized browsing experience. It highlights selected Jaguar models through dedicated pages, allowing visitors to explore the vehicles, their details, and gallery visuals.

## Features

- **Home Page** – A redesigned landing page inspired by Jaguar's visual identity.
- **Vehicle Showcase** – Explore Jaguar models featured exclusively on this website.
- **Dealership Page** – A dedicated page for dealership-related information.
- **Gallery** – A visual collection of vehicle images.
